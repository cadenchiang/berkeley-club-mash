# clubmash

head-to-head voting app that ranks berkeley student clubs with an elo rating system. my first ever project.

**40,000+ votes in under 24 hours.**

## what it does
- vote between two clubs, one matchup at a time
- elo ratings update live from every vote
- bot and spam detection keeps the rankings honest

## built with
- react + vite
- supabase

## getting started
```bash
npm install
npm run dev
```
copy `.env.example` to `.env` and add your supabase keys.
